# Cwhale 本地运营工作台

工作台用于维护全域/定向通知、灰度模型、用户赠与额度和管理员审计记录。管理 API 必须在服务端部署并配置管理员邮箱白名单后才可用。

## 启动

在 Windows PowerShell 中从项目根目录运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\tool\start_admin_workbench.ps1
```

然后访问 `http://127.0.0.1:8765/`。结束时在 PowerShell 按 `Ctrl+C`。页面只由本机提供，不需要公开部署。

在页面中填写已部署的账号服务 API 地址、管理员邮箱和密码。密码通过 HTTPS 登录接口发送，登录后立即清空输入框；访问令牌只保存在当前页面内存，不写入本机存储。刷新或关闭页面后需要重新登录。账号必须已验证邮箱，并列入服务端 `CWH_ADMIN_EMAILS` 白名单。

页面支持发布全域或指定账号通知、维护灰度模型、赠与/撤销 Token 额度和查看审计记录。指定受众通知及额度赠与使用工作台搜索结果里的账号 ID。模型内部 ID 创建后保持稳定；编辑模型时留空 API Key 会保留服务器上的现有密钥。

## 服务端配置

在账号服务的私有环境文件中配置 `CWH_ADMIN_EMAILS`，值为允许管理工作台的已验证邮箱，多个邮箱用英文逗号分隔。仅修改部署环境配置，不要提交包含真实地址、邮箱、密钥或 SMTP 凭据的环境文件。

## 权限边界

- 普通用户只能读取面向自己的通知、已授予的模型和额度。
- 全域通知面向所有账号；指定受众通知必须绑定服务端选出的账号 ID。
- 客户端提交的模型地址、模型代号和 Key 不得覆盖赠与模型的服务端配置。
- 赠与资格撤销后，后续请求必须在服务端拒绝；不能依赖隐藏界面来回收权限。
- 所有通知发布、模型维护、赠与和撤销操作写入服务端审计记录。
- 模型启用状态、思考能力和图片/文件能力由服务端登记；客户端不能用请求字段覆盖获赠模型的上游地址或密钥。
