应用如何处理数据

Cwhale 不提供模型 API 代理、云端聊天存储、广告、分析或遥测。邮箱登录使用由 Cwhale 运维的账号认证服务。

当用户注册、登录、验证邮箱或找回密码时，邮箱地址及相应认证请求会通过 HTTPS 发送到 Cwhale 账号服务。服务器保存邮箱、Argon2id 密码哈希、邮箱验证状态、验证码哈希与有效期、刷新令牌哈希和限流记录；不会保存明文密码、明文验证码或明文刷新令牌。验证码邮件由 163 邮件服务发送，因此邮件服务会处理收件地址和邮件内容。账号服务不接收聊天记录、记忆、模型 API Key 或用户文件。聊天与记忆仍保存在本机，登录不会把聊天内容提供给账号服务，也不会改变聊天数据的存储位置。

聊天记录、窗口独立记忆、手动记事、滚动摘要和全局重要记忆保存在本机应用数据目录。旧版 chats-v1.json 会无损迁移到 chats-v2.json 元数据索引及 threads/ 下按对话分块的消息原文；新文件成功保存后才删除旧文件。聊天页默认载入最近 60 条，向上每页读取 30 条，活动范围最多 120 条且正文约 100,000 字符；完整原文一直保留本机，分页只影响显示，模型上下文仍遵循摘要游标和现有压缩规则。Android 系统备份已关闭；iOS 应用支持目录已排除备份。普通窗口记忆不跨对话混用；全局重要记忆按当前问题匹配并跨窗口使用，用户明确为 AI 设定的称呼会作为稳定偏好记住并随每次请求提供。自动路由不使用 AI 分类、向量数据库或云端记忆服务。全局重要记忆页可按主题删除其所有历史版本和所有窗口副本，不会创建覆盖记录。开启深度思考后，模型推理内容也保存在本机。多个 API 配置档案（显示名、服务商、Base URL、模型、API Key、上下文上限和自动压缩设置）、默认档案 ID、全局提示词、时间戳和联网搜索开关保存在手机安全存储中。每个对话各自保存档案 ID；新对话使用默认档案。上下文长度以 K/1M 显示并限制为 16K 至 1M，每档分别计算占比和自动压缩。

用户可以在全局重要记忆页面手动添加主题和内容，作为带本地时间戳的全局记忆保存在手机。全局系统提示词可在设置二级页面编辑，保存在本机设置；保存后会作为 system 前缀发送到当前激活的 API，并随每次请求提交，包括工具后续请求和摘要压缩请求。

API Key 不写进安装包、聊天记录或明文配置文件。iOS 使用 Keychain；Android 使用 RSA-OAEP 密钥包裹与 AES-GCM 数据加密。应用不会把密钥上传到 Cwhale 服务端。用户发送请求时，手机会通过 HTTPS 将 Key 放入 Authorization: Bearer 请求头，直接发送到当前档案配置的 Base URL 做 API 鉴权；因此密钥会到达所选服务商。设备或操作系统遭到攻破时，本机密钥仍可能泄露。

发给当前对话选定的 API 的数据

默认档案使用 DeepSeek OpenAI 兼容 Chat Completions：POST https://api.deepseek.com/chat/completions；可增加其他 OpenAI 兼容 Chat Completions 档案，不实现或宣称支持服务商专有协议。以 JSON 发送 model、messages、stream: true 和按需使用的 tools；回复通过 text/event-stream（SSE）流式返回。只有当前对话选择 DeepSeek API 时才发送 DeepSeek thinking 参数。当用户发送消息时，手机会通过 HTTPS 将当前消息、窗口记忆、近期上下文、匹配到的全局重要记忆，以及用户配置的全局系统提示词直接发送给当前对话选定档案的 Base URL。手动或自动 AI 压缩时，较早对话也会作为额外请求直接发送给当前档案服务商，可能产生额外费用；原始聊天仍留在本机。上下文占比为本机估算。

请求内容由当前选定服务商按其服务条款处理，可能留存请求或按服务价格向用户计费。Cwhale 不接收或转发 API 请求。

联网搜索、天气与文件

联网搜索开关默认关闭，用户打开后会保持开启直到手动关闭；发送消息或切换对话不会自动关闭。开关只授权当前消息的模型自行判断是否搜索；开关关闭时，用户明确要求搜索才会提供搜索工具。模型发起搜索、选择查询词和页码，再用 open_web_page 读取候选来源。手机直接请求 DuckDuckGo HTML、DuckDuckGo Lite 和百度公开搜索页；每次工具调用读取一页，不设应用级 3 条或 25 条总结果上限。模型根据可信证据决定是否继续翻页或调整查询，并在证据足够后停止。搜索结果和网页正文作为工具结果交给模型综合回答，应用不会直接把搜索结果当作答复。搜索关键词会发送给搜索站点，被选中的来源网页会由手机直接读取。聊天中的引用以蓝色短链接显示，点击后交给系统浏览器打开。搜索失败会作为工具结果交给模型，模型应如实说明；应用不会伪装搜索成功。网页读取仅接受公开 HTTPS 域名，不接受 IP 字面量、localhost、内网或本地文件。应用固定的 DuckDuckGo 和百度搜索入口使用精确 HTTPS 主机名白名单，以兼容 VPN 合成 DNS；网页 TLS 证书仍由系统校验。其他结果网页还需通过公开 DNS 地址校验。天气工具固定抓取 wttr.in 的公开天气 HTML 网页，由手机直连并在本机用 Trafilatura 提取当前天气与预报，不需要 Weather API Key。城市名称和设备网络地址会发送给 wttr.in；抓取内容随工具结果直接发送给当前对话选定档案，助手回复保存在本机聊天记录中。天气回复标注 wttr.in 来源和手机本地抓取时间；该站点可能限流或暂时不可用。

用户选择的 Word、PowerPoint、Excel、CSV 或文本文件先在本机提取文字。只有用户发送附件消息后，提取内容才随对话直连当前对话选定档案。生成的 .docx、.pptx 和 .xlsx 文件保存在应用本机目录，并以文件卡片显示在当前聊天中。用户点击卡片后，由系统展示可打开该格式的应用；Cwhale 不内置文档编辑器，也不会上传或接收生成文件。

Cwhale 免费模型（主动切换）

用户可在聊天页面切换到 Cwhale 免费模型。首次切换前须登录 Cwhale 账号并同意数据发送说明；该登录仅用于 Cwhale 应用身份，不会把 Cwhale 账号凭据提供给免费模型服务商。该模型由第三方免费模型网关自动路由到可用上游，手机直接连接网关，不发送 API Key；免费请求可能按网络出口 IP 限流。其他 API 档案仍按各自配置使用凭据。

用户同意后，聊天消息、回答所需的本窗口上下文、用户选择的附件，以及本轮需要的工具后续和摘要请求会发送给免费模型网关及其自动选择的上游服务商。服务商可能依其条款处理或保留请求内容，实际模型上游也可能变化。请勿发送密码、支付资料、健康等敏感信息。全局重要记忆默认不会自动注入；本窗口上下文和用户配置的全局系统提示词仍可能按本轮请求发送。用户可在“设置 → 隐私 → Cwhale 免费模型数据授权”撤销；撤销后，聊天、工具后续、文档摘要和压缩请求都会被拦截，直至重新同意。撤销不会撤回已发送的数据。

“每次请求附带本地时间戳”由用户手动开启，默认关闭。开启后，每次模型 API 请求（包括工具调用和较长对话摘要）都会附带设备本地日期、时间和时区；时间戳不写入聊天记录。

删除与控制

用户可以删除单段对话及其生成文件、清空本机全部聊天和生成文件，也可以在全局重要记忆页按主题删除所有历史版本和各窗口副本，或在模型设置中清除 API Key。分页不会删除旧聊天正文。操作系统的设备备份行为由用户的设备和账户设置决定。
