第二步

导入 DeepSeek 对话

✦

将已有对话导入 Cwhale，原有记录不会受到影响。导入文件保存在本机。

支持 DeepSeek 导出的 ZIP 文件或下载链接。也可以暂时跳过，以后从侧边栏导入。

第三步

配置 DeepSeek API

✦

如果你已经有 API Key，可以粘贴到下方；没有的话之后再配置。

加密存储在本机
请妥善保存 API Key，不要暴露给不可信的服务商或第三方，以免被盗用。

第四步 · 可选

注册并登录账号

✦

填写邮箱并完成验证后，账号会自动登录，可领取即将开放的免费额度。也可以跳过，继续使用全部功能。

· · · · · ·

账号仅用于登录和未来额度发放，不会读取本机聊天内容。使用免费额度时，会说明相关内容的发送范围。
