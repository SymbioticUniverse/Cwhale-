# 社区发布与首选调度施工单

## 从作者发布到用户安装

1. 作者将签名后的 .pcard 发布在自己的 HTTPS 下载地址，或通过文件直接分享给用户。两种方式使用相同的安装器。
2. 如果希望被社区目录收录，作者提交包下载地址。目录维护方下载完整包，执行 PKG-01 到 PKG-03 对应的结构、签名与资源检查，并检查申报能力对应的示例查询。目录展示作者、服务方、版本、下载大小、权限、外部域名和已验证能力。媒体是否可试听或可整段播放分别标注。
3. 目录为该版本登记 pluginId、packageVersion、作者公钥指纹、整包 SHA-256、HTTPS 下载 URL 和撤回状态。整包哈希按实际交付的 ZIP 字节计算，重压缩要重新登记。目录只固定首次审核通过的作者公钥，同 ID 换钥进入独立的身份重新核验流程。
4. 用户主动浏览目录并选中版本后，手机从该目录公示的 HTTPS 地址下载，先核对目录哈希，再进入本机安装器的验签与授权。目录可以是独立静态站，离线分享无需社区账号。安装成功后只有本机的已启用能力参与当前用户的调度。
5. 更新复用相同准入流程。作者撤回版本后目录停止分发，并标记原因。宿主只有在用户主动刷新目录后才知道撤回，明确提示用户，保留可读历史快照。离线安装能力与远程撤回的生效时间分别向用户说明。

## 一项能力怎样决出首选

这是 v0.1 的建议评分基线，用于双方按相同输入算出相同排序。权重是产品选择，可按公开规则修订。榜单按 capability、具体用户动作、地区、设备能力、权益档和规则版本分别生成。例如只可打开来源页的电影插件可以参加“查找来源”，不能参加“直接播放正片”。

| 步骤 | 执行与产物 |
|---|---|
| 固定赛题 | 发布 query 与期望资源/动作、每题重复次数、网络条件、设备、是否有会员、冷/热启动、观察截止时间。服务不可用也记录一个样本 |
| 测正确性 C | 实际命中目标且交付承诺动作的样本数 / 有效样本总数。媒体必须收到首段实际音视频，行情必须匹配证券、市场和时间条件。空壳卡片不算成功 |
| 测接入速度 L | 从派发请求到用户可用结果，失败按观察截止时间计。取所有样本的第 95 百分位耗时 t（秒，排序后取第 ceil(0.95n) 个）。对外发布的该组快慢基准为 f、s，s 大于 f。L = clamp((s − t)/(s − f), 0, 1) |
| 测服务质量 Q | 预先登记该组二次动作，例如开始后保持可用到规定时点、暂停生效、正确刷新或来源页仍匹配。每个样本检查同样数量的项目。Q 为通过项数 / 总项数，无法进入二次动作的样本该项计零 |
| 评分及留档 | 原始分 = 100 × (0.50C + 0.25L + 0.25Q)。公布样本数、分项、原始延迟、最终分、评测日期、包版本和规则版本。排序使用未四舍五入的原始分 |

**可复算样例。** 某组规定 f=1 秒、s=5 秒，插件的 C=0.90、t=2 秒、Q=0.80。L 等于 0.75，得分为 83.75。新版本没有参赛记录时显示“未评测”，旧包成绩不自动转给新包。

**单次调度顺序。** 先过滤未安装、已禁用、权限或设备不符的候选，然后使用用户明确指定，其次使用用户为该能力指定的默认。其余选本机已有的、条件相符的评测结果，先比较原始分，再比较 C，再比较 t，最终按插件 ID 的 ASCII 升序。没有适用榜单且存在多个候选时让用户挑选；仅有一个合格时可以使用。权益未知时不显示“可完整播放”，待来源实际返回。首选没给出用户需要的动作时展示已有结果，可提供其他已配置来源供用户切换。服务商返回的卡片与模型回复均无权自行修改榜单、默认服务或权限。
